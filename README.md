
# AutoValue - Car Price Prediction System

## Project Description

AutoValue is a machine learning web application
that predicts used car selling prices based on
vehicle specifications.

## Features

- Dataset upload
- Data exploration
- Missing value analysis
- Data preprocessing
- Feature engineering
- Regression model training
- Model evaluation
- Interactive price prediction
- Model download

## Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Plotly
- Joblib

## Machine Learning Algorithms

1. Random Forest Regression
2. Extra Trees Regression
3. Gradient Boosting Regression

## Installation

Install dependencies:

pip install -r requirements.txt

## Run Application

streamlit run app.py

## Dataset

Upload a CSV containing vehicle information
and a numerical selling price column.

## Evaluation Metrics

- Mean Absolute Error
- Root Mean Squared Error
- R² Score
